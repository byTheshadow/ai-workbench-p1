GUIDE & CREATOR RESOURCES

工作台核心功能 (ABOUT WORKBENCH)

  • 双独立 API 凭证管理：支持独立配置 AI 聊天助手与 AI 绘图引擎（NovelAI、Stable Diffusion WebUI、通用 /v1 接口）的 API 连接，数据均保留在用户本地浏览器中。
  • 双轨存储与缩略图加速：偏好与提示词保存在 LocalStorage，高清原始图片保存在本地 IndexedDB 数据库；支持图片入库时生成轻量缩略图以提升画廊流畅度。
  • 多草稿与任务调度：提供多标签草稿箱，支持单独管理主旨要求、正向词、画师实验室与参数，配合并发任务队列有序生成。
  • 画廊与批量管理：支持对生成的历史图片进行多选、批量导出保存以及批量删除等操作。

AI 生图核心语法指南 (PROMPT SYNTAX GUIDE)

1. 标签化推荐结构 (Prompt Structure)
NovelAI 及动漫扩散模型基于 Danbooru 标签体系训练，推荐使用半角逗号分隔的 Tag 结构：
[画质/风格前缀] + [主体人物与特征] + [服装与道具] + [姿势与表情] + [背景环境与镜头光影] + [画师串]

2. 权重语法对比 (Numeric Emphasis)
• NovelAI v4 / v4.5 数值语法：使用数值前缀与双冒号包裹。增强如 1.2::long hair::，减弱如 0.8::long hair::；画师专用写法如 1.25::artist:wlop::。
• Stable Diffusion / 通用语法：使用经典圆括号权重，如 (long hair:1.2) 或 (artist:wlop:1.25)。

3. 常见负面提示词参考 (Negative Prompts)
• 二次元动漫风通用过滤：
lowres, bad anatomy, bad hands, text, error, missing fingers, extra digit, fewer digits, cropped, worst quality, low quality, normal quality, jpeg artifacts, signature, watermark, username, blurry
• 规避 3D 渲染感：可在负面词中追加 3d, photorealistic, render, realistic。

4. 人体与构图控制建议
• 肢体与手部控制：避免模糊词汇，推荐使用明确动词如 sitting, hands on hips。必要时正向添加 perfect hands, detailed fingers。
• 镜头景深：加入 cinematic lighting, depth of field, close-up, cowboy shot, wide shot 等词汇以精确控制画面取景范围与光影层次。

+ 常见错误诊断指南 (TROUBLESHOOTING HELP)
1. CORS 跨域代理报错 (403 Forbidden / Failed to fetch)
• 说明：请求被浏览器跨域策略拦截。通常发生在直连 NovelAI 时。
• 对策：请在“设置”面板中确保填写了可用的 CORS 跨域代理地址，或为浏览器安装并启用 CORS 解除插件。
2. NovelAI 401 Unauthorized / 身份验证失败
• 说明：NovelAI Key 无效或未配置。
• 对策：检查“设置”面板中的 NovelAI API Key 是否填写正确。它应该是以 pst- 开头的令牌字符串。
3. Stable Diffusion Connection Refused / 500 报错
• 说明：无法连接到本地或远程 SD WebUI 接口。
• 对策：检查“设置”中的 SD 地址是否拼错（默认 http://127.0.0.1:7860），并确保 SD WebUI 启动参数中包含了 --api 和 --cors-allow-origins=*。
4. 422 Unprocessable Entity / 400 Bad Request
• 说明：请求参数无效或超出服务限制。
• 对策：某些 API 对图片生成尺寸、步数有严格阈值，请尝试调小分辨率、步数，或检查选择的模型是否有效。
